# Historical exploratory annotations

The JSON and text files in this directory are saved LLM judgments from the earlier
exploratory comparison. They are not deterministic benchmark results or reliable
false-positive counts. No new LLM grading is performed by `eval.mulder`.

In particular, the 11–13 disputed/unsupported flags belonged to the regraded Mulder
reports, not Chain of Proof's report. The earlier 11/20 figure for our report also
came from this separate rubric and is retired from performance reporting.

See [evaluation](../../eval/EVALUATION.md) for current output coverage, the typed
common-test work, and the distinction between answer matching and proof verification.
