# Examination report format

The HTML report uses numbered examination sections and lettered appendices. The main report contains an executive summary, request and scope, evidence inventory, methods, findings, any supplied conclusions, evidence disposition, and authorization. Optional incident-response fields describe impact, cause, response and recovery, and recommended actions. They appear only when the report author supplies them.

The summary indexes source records by topic and links to findings. The detailed findings show recorded properties beside their source references. Exact certificate statements remain unchanged in expandable sections. Printing includes those statements. Technical logs, refusals, evidence copies, and proof source belong in appendices. A separate Limits section is not included.

Report number, version, organisation address, request date, receipt method, other submitted items, procedures, disposition, and authorizer are editable report fields. They do not create evidence or proof. The renderer does not invent custody, procedures, tool versions, incident impact, or conclusions. The signature space remains blank.

## Research basis

- [SWGDE Requirements for Report Writing in Digital and Multimedia Forensics, 18-Q-002, approved version 1.0, 20 November 2018](https://www.swgde.org/documents/published-complete-listing/18-q-002-swgde-requirements-for-report-writing-in-digital-and-multimedia-forensics/): minimum report content includes identification, request, items, examination results, supported opinions, disposition, and authorization. SWGDE does not prescribe one layout.
- [NIST SP 800-86, August 2006, section 3.4](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-86.pdf): reporting should fit its audience, consider alternative explanations, and communicate useful results. This informs the summary and access to technical detail.
- [NIST SP 800-61 Revision 3, April 2025, RS.AN and RC.RP-06](https://nvlpubs.nist.gov/nistpubs/specialpublications/nist.sp.800-61r3.pdf): incident documentation covers events, affected resources, causes, response, recovery, and lessons. Those assessments require supplied information.
- [ASD-STE100, Issue 9, 15 January 2025](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf): the authored report prose uses short sentences, active voice, consistent terms, and one topic per paragraph. Descriptive sentences target at most 25 words. Instructions target at most 20 words. The wording avoids semicolons and defines technical terms in a glossary.

The STE writing rules apply to authored report prose. Certificate statements, source values, diagnostic records, and examiner-entered text remain literal. The renderer does not claim that arbitrary source text, or the whole exported bundle, has formal STE conformance. Changing certificate wording requires changes to the certificate generator and its verification contract.

Print page counters use browser CSS margin boxes. Support depends on the print engine. Report authorization requires the examiner's review and signature.
